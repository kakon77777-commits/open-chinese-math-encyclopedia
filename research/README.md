# OCME research packets

`research/` 保存 Atlas seed 物化成 Canonical MKO 之前的研究紀錄。研究包不是 Evidence Object，也不會把來源的權威性轉換成 OCME 已完成的形式證明。

每份研究包至少記錄：

- Atlas 與目標 MKO 識別碼；
- 範圍、語義選擇與不涵蓋事項；
- 可追溯的來源、授權資訊與存取日期；
- 來源支持的主張與 OCME 自行採用的編輯決定；
- 公式、依賴、架構分類與形式化候選；
- Evidence 邊界、未決義務與審查狀態。

狀態 `ai_candidate_complete` 表示本地 AI 已完成可供審查的候選稿，不表示人類專家已核准，也不表示已產生計算或形式證明 Evidence。
